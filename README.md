# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения».

## Бизнес-задача
Расчёт и визуализация ключевых показателей эффективности (KPI) предприятия на основе данных о выручке и затратах. Приложение автоматизирует расчёт средней выручки и рентабельности.

## Используемые технологии
- Python 3.14 — язык программирования
- pandas 3.0.6 — обработка и анализ данных
- matplotlib 3.11.2 — визуализация данных
- Git и GitHub — контроль версий и командная работа
- VS Code — интегрированная среда разработки

## Инструкция по запуску (Windows)

1. Открыть терминал в папке проекта.

2. Создать виртуальное окружение:
python -m venv .venv

3. Активировать виртуальное окружение:
.venv\Scripts\activate

4. Установить зависимости:
pip install -r requirements.txt

5. Запустить программу:
python main.py

## Структура проекта
- main.py — основной скрипт с расчётом KPI
- requirements.txt — зависимости проекта
- .gitignore — исключения для Git
- docs/business_requirements.md — бизнес-требования
- docs/control_questions.md — ответы на контрольные вопросы
