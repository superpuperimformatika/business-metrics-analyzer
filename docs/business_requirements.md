# Бизнес-требования

## Цель приложения
Автоматизация расчёта ключевых показателей эффективности (KPI) предприятия на основе данных о выручке и затратах.

## Функциональные требования
- Загрузка данных о выручке и затратах по месяцам
- Расчёт средней выручки
- Расчёт рентабельности
- Визуализация динамики показателей

## Нефункциональные требования
- Python 3.14
- Кроссплатформенность (Windows, macOS, Linux)
- Простота запуска (venv + requirements.txt)

## Стек
- pandas — обработка данных
- matplotlib — визуализация
