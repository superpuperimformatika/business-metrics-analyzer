## Домашнее задание: Моделирование бизнес-процессов

### 1. Бизнес-процесс «Как есть» (AS-IS)
**Описание:** В данный момент процесс сбора и анализа KPI продаж в компании ООО «Ритейл-Аналитика» полностью ручной. 
* Менеджеры по продажам выгружают сырые данные из учетных систем.
* Аналитики вручную переносят данные в Excel-таблицы.
* С помощью сложных формул и сводных таблиц формируются отчеты.
* Коммерческий директор запрашивает отчеты по мере необходимости. 

**Проблемы (боли):**
* Время формирования отчетов занимает 2–3 дня.
* Высокий риск человеческих ошибок при копировании данных.
* Нет оперативного доступа к KPI (данные всегда «вчерашние»).
* Сложно консолидировать данные из разных источников.

### 2. Бизнес-процесс «Как будет» (TO-BE)
**Описание:** После внедрения веб-приложения «Business Metrics Analyzer» процесс становится автоматизированным.
* Система автоматически загружает и обрабатывает данные о продажах.
* Дашборд с ключевыми KPI (выручка, средний чек, конверсия, рентабельность) обновляется в реальном времени (или по расписанию).
* Пользователи (директор, менеджеры, аналитики) заходят в систему и видят актуальные данные.
* Аналитики могут выгружать готовые отчеты в Excel одной кнопкой.

**Преимущества:**
* Время получения отчета сокращается с 2-3 дней до 3 секунд.
* Исключается человеческий фактор.
* Единый источник достоверных данных для всех отделов.
