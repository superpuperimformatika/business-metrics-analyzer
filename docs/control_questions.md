# Ответы на контрольные вопросы

## 1. Чем отличается Git от GitHub?
Git — распределённая система контроля версий, работает локально на компьютере. GitHub — облачная платформа для хранения Git-репозиториев и совместной работы.

## 2. Для чего используется виртуальное окружение Python?
Для изоляции зависимостей проекта: чтобы библиотеки одного проекта не конфликтовали с библиотеками другого.

## 3. Что такое commit, branch, remote, pull request?
- Commit — фиксация изменений в истории проекта.
- Branch — отдельная ветка разработки.
- Remote — удалённый репозиторий (например, на GitHub).
- Pull Request — запрос на слияние изменений из одной ветки в другую.

## 4. Зачем нужен файл .gitignore?
Он указывает, какие файлы и папки не должны попадать в репозиторий (например, .venv, __pycache__, *.xlsx).

## 5. Как организовать командную работу над бизнес-приложением с помощью Git?
Каждый разработчик создаёт свою ветку от main, делает коммиты и push, открывает Pull Request. Второй участник делает ревью и merge. После merge все обновляют локальный main командой git pull.

## 6. Какие файлы обязательно должны быть в репозитории учебного проекта?
README.md, .gitignore, requirements.txt, исходный код (main.py), документация (docs/).

## 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?
При слиянии возникнет конфликт. Git покажет конфликтующие участки, и разработчик должен разрешить их вручную, выбрав нужные строки.
