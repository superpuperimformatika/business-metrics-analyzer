# Описание ключевых Use Case

## Use Case 1: Формирование отчёта

| Поле | Значение |
| :--- | :--- |
| **Название** | Формирование отчёта |
| **Актор** | Аналитик |
| **Предусловие** | Пользователь авторизован в системе, данные о продажах загружены. |
| **Основной поток** | 1. Пользователь выбирает тип отчёта.<br>2. Указывает необходимый период.<br>3. Нажимает кнопку «Сформировать».<br>4. Система формирует отчёт.<br>5. Пользователь просматривает отчёт. |
| **Альтернативный поток** | Если данных за выбранный период нет – система выводит сообщение «Данные не найдены». |
| **Постусловие** | Отчёт сформирован и доступен для экспорта в Excel. |

## Use Case 2: Загрузка данных о продажах

| Поле | Значение |
| :--- | :--- |
| **Название** | Загрузка данных о продажах |
| **Актор** | Менеджер по продажам |
| **Предусловие** | Пользователь авторизован, имеет права на загрузку данных. |
| **Основной поток** | 1. Пользователь открывает раздел загрузки данных.<br>2. Выбирает файл с данными (Excel/CSV).<br>3. Нажимает кнопку «Загрузить».<br>4. Система проверяет формат файла.<br>5. Система сохраняет данные в базу и обновляет KPI на дашборде. |
| **Альтернативный поток** | Если формат файла неверный – система выводит ошибку и просит загрузить файл заново. |
| **Постусловие** | Данные успешно загружены, дашборд обновлен. |
